# 🩺 Diabetes Prediction System

## Overview

The Diabetes Prediction System is a Machine Learning project that predicts whether a person may have diabetes based on various health-related parameters. The model is trained using the Pima Indians Diabetes Dataset and uses Logistic Regression for classification.

A user-friendly Streamlit web application allows users to enter health information and receive an instant diabetes risk prediction along with a probability score.

---

## Features

✅ Data preprocessing and cleaning

✅ Feature scaling using StandardScaler

✅ Logistic Regression classification model

✅ Interactive Streamlit web interface

✅ User input-based prediction

✅ Diabetes probability estimation

✅ Model performance evaluation

✅ Real-time prediction results

---

## Dataset

The project uses the Pima Indians Diabetes Dataset with the following features:

* Pregnancies
* Glucose
* BloodPressure
* SkinThickness
* Insulin
* BMI
* DiabetesPedigreeFunction
* Age

### Target Variable

**Outcome**

* 0 = No Diabetes
* 1 = Diabetes

## Model Performance

### Evaluation Metrics

| Metric    | Score  |
| --------- | ------ |
| Accuracy  | 75.32% |
| Precision | 63.79% |
| Recall    | 67.27% |
| F1 Score  | 65.49% |

### Confusion Matrix

```text
[[78 21]
 [18 37]]
```

### Interpretation

* The model correctly predicts approximately 75% of cases.
* Precision indicates how often positive diabetes predictions are correct.
* Recall measures the model's ability to identify actual diabetes cases.
* F1 Score provides a balance between Precision and Recall.

## Installation

Clone the repository:

```bash
git clone https://github.com/omsoni2795-hash/diabetes-prediction.git
```

Move into the project directory:

```bash
cd diabetes-prediction
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the virtual environment:

### Windows

```bash
.venv\Scripts\activate
```

Install required packages:

```bash
pip install -r requirements.txt
```

---

## Running the Application

Run the Streamlit app:

```bash
streamlit run app.py
```

or

```bash
python -m streamlit run app.py
```

The application will open automatically in your browser.
